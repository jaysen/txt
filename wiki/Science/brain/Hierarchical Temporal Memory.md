## The HTM Learning Algorithm
A model for the fundamental algorithm for learning and intelligence in the [Neocortex](Neocortex.md) . 
#brain #theory #intelligence #sci #learning 

### Features
- The cortex stores sequences of patterns, it recalls patterns auto-associatively, and it stores invariant patterns in hierarchies.
- Hierarchical 
	- compositional
	-  it stores invariant patterns in hierarchies
- Temporal
	- Sequences in time
	- time based patterns
- Memory
	-  it recalls patterns auto-associatively
- SDR - [Sparsely Distributed Representations](Sparsely%20Distributed%20Representations.md)
