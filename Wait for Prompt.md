## Consciousness as a running loop: how the argument developed

1. **Starting point: [Michael-Graziano](Michael-Graziano)'s [Attention Schema Theory of Consciousness](wiki/Science/brain/Attention%20Schema%20Theory%20of%20Consciousness.md)
   - [Consciousness](wiki/Science/brain/Consciousness.md) is a simplified model of our own attention
   - Function: plan and control attention, filter out subconscious processing
   - Evolutionarily plausible, likely emerged early
   - Fits with global workspace ideas

2. **Premise: consciousness is computable**
   - It could run on hardware other than a brain

3. **"Wait for prompt" hypothesis**
   - An [LLM](LLM) needs input to do anything. There is no background 'thinking'. If you don't prompt the inference machine, it does nothing.
   - Proposal: maybe all consciousness is like this, and senses are just prompts. 
   - Question: would a computed mind do anything without input?

4. **Challenge: two meanings of "needs input"**
   - Trivial: any process needs something to process
   - Strong: sits idle until poked, runs once, halts. This describes the LLM.
   - The brain never halts (sensory deprivation, sleep), so the strong version doesn't fit it
   - Fire vs match: a fire is always burning, a match flares once per strike

5. **Resolution: the self-referential feedback loop**
   - The brain supplies its own input: each output feeds back as the next input
   - The stream of consciousness is that loop
   - External input perturbs a loop that is already running

6. **"While conscious" refinement**
   - The loop stops in dreamless sleep, anesthesia, and coma, even though the hardware is intact
   - Claim: consciousness *is* the loop running, not a precondition for it
   - Graziano supplies the content (what is modeled); the loop supplies the process (the running)

7. **Link to Hofstadter's *I Am a Strange Loop***
   - His view: the self is self-reference that crosses levels (from Gödel). It's about *reference*.
   - This view: the self is a continuously executing loop. It's about *execution*.
   - This handles anesthesia better: the structure persists, but execution stops
   - Both views favor structure over substrate

8. **What survives from "wait for prompt"**
   - Consciousness can be prompted: external input is injected into the running stream
   - The loop also prompts itself (unbidden thoughts)
   - An LLM only takes external prompts: no self-prompting, no persistence between prompts

9. **Symmetry: potential vs actual**
   - An anesthetized brain and an LLM on disk are in the same state: machinery present, loop off
   - Difference: the brain can restart and sustain its own loop; the LLM can't
   - Building that capability is an engineering gap, not a gap in principle

10. **Conclusion**
    - Consciousness is a *process* a machine runs, not a *substance* it has
    - The question shifts from "what is it made of?" to "is the loop running?"
